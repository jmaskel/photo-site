Put your original photos in this folder (JPEG, PNG, TIFF, WebP or AVIF).

- They appear on the site sorted by filename, so prefix them to control order:
  `01-harbor.jpg`, `02-desert.jpg`, ...
- Export at full quality, longest edge 2560px or larger. The build makes all smaller sizes.
- Alt text and captions are set in `site.config.json` under `photos`, keyed by filename.
